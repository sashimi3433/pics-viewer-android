# PICS ビューア（高度化PICS 信号情報リーダー）

高度化PICS 対応の歩行者用信号機が BLE アドバタイズで常時送信している信号情報を、
Android 端末で受信して表示するアプリです。受信専用で、信号機への送信・制御は行いません。

- パッケージ: `dev.sashimi.picsviewer`
- minSdk 26 / targetSdk 35
- Kotlin + Jetpack Compose (Material 3)

## できること

- Company ID `0x01CE` の BLE アドバタイズを自動スキャン（GATT 接続なし）
- 交差点ID・送信機ID・緯度経度・信号6チャンネルを1つのカードに集約
- チャンネルごとに「赤 / 青 / 青点滅 / 対象外」と残り秒を表示
- タイルをタップすると「注目チャンネル」として大きく表示（交差点ごとに記憶）
- 注目チャンネルの変化を音声読み上げ＋振動で通知（設定でON/OFF）
- 受信ログ（生の16進データ付き）を最大200件保持し、共有シートから書き出し
- 信号機がなくても確認できるデモモード（設定 or 空画面のリンクから）
- 全国596箇所の高度化PICS整備交差点マップ（現在地から近い順・ピンタップで詳細）
- 残り時間は円形9分割リング（下1つは長めの固定セグメントで常に信号色、残り8つがM3Eのprimary色で減少）
- セグメントは角丸（M3E風）
- Material 3 Expressive 風のUI + Material You（Android 12+ は壁紙の配色に追従）

## 対応交差点マップ

- データ: 警察庁「高度化PICS整備交差点」リスト（596箇所、`assets/pics_intersections.json`）
- 地図: osmdroid + OpenStreetMap タイル（APIキー不要）
- 低ズームでは件数バッジにクラスタリング、拡大すると個別ピン
- 現在地を許可すると、近い順に3件を距離付きで表示


## インストール

```sh
adb install -r app-debug.apk
```

端末に直接コピーする場合は、ファイルマネージャから APK を開いてインストール
（提供元不明のアプリの許可が必要）。

初回起動時に Bluetooth のスキャン権限を求められます。許可すると自動で受信を始めます。

## 使い方（実地）

1. アプリを開く（画面が見えている間だけスキャンします）
2. 信号機の近く（数m〜十数m）に立つ
3. 「交差点 xxxxxxxx」のカードが出たら、自分の向きのランプをタップして注目
4. 注目チャンネルが切り替わると、読み上げと振動で知らせます
5. うまく取れないときは「受信ログを共有」で生データを送ってください

## 受信仕様（アドバタイズの 0x01CE 以降 24 バイト）

| バイト | 内容 |
|---|---|
| 0 | バージョン（実測 0x58） |
| 1 | フラグ（実測 0x01） |
| 2 | メッセージタイプ 0=識別 / 1=位置 / 2=信号 |
| 3 | メッセージID（1秒ごとに増加） |
| 4..5 | 予約 |
| 6..9 | 交差点ID（ビッグエンディアン） |
| 10.. | タイプ別ペイロード |

- タイプ0: 10..23 が ASCII の送信機ID（例 `UTMS_PICS0001`）
- タイプ1: 10..13 が緯度 int32BE / 1e6、14..17 が経度 int32BE / 1e6
- タイプ2: 10..15 が6チャンネル分。1バイト = 上位4bit「残り時間の段階」/ 下位4bit「状態」
  - 状態: 0=信号なし, 1=赤, 2=青点滅, 3=青, 4=対象外
  - 上位4bit は **0〜7 の8段階**（位相の残りを8分割した値）。秒ではない
    - 実測: 赤は約11秒/段階（赤全体 約90秒）、青は約1.6秒/段階（青全体 約12秒）
    - 公式アプリ「信GO!」も秒数ではなく横バーで表示している
  - 上位4bit が 8 以上、または 0xFF は「不明・データなし」

実測ログ（神奈川県内）で検証済み。解析は `PicsParserTest` に実パケットを固定しています。

## ビルド

```sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=/opt/homebrew/share/android-commandlinetools
./gradlew :app:assembleDebug          # APK: app/build/outputs/apk/debug/
./gradlew :app:testDebugUnitTest      # パーサの単体テスト
```

## 注意

- 受信専用です。電波法上の送信・信号制御は一切行いません。
- 公式アプリ（日本信号「信GO!」）ではありません。信号機の設置状況や送信内容は
  自治体・警察庁の整備状況によります。
- Android 11 以下では BLE スキャンのために位置情報サービスをONにする必要があります。
- Company ID `0x01CE` は HOUWA SYSTEM DESIGN, k.k. に割り当てられています。
